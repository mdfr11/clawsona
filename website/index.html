Bring a mini-PC.
Give it a name.

Start with local speech and the official DeepSeek API through OpenClaw. No extra speech subscription required.

What you'll need

Python 3.11–3.13, uv, OpenClaw, a microphone and speakers. Target platforms: Linux and macOS.

The code is free. Hosted model and optional voice APIs have separate charges.

Download source · v0.3.0View on GitHub
Prepare your checkoutONCE

Unpack the source and open a terminal in that folder. Install PortAudio first: Debian/Ubuntu libportaudio2, or macOS brew install portaudio. 

uv python install 3.12
uv sync --python 3.12 --frozen
cp -n .env.example .env
Pick an identity.ENV

Add your own DeepSeek API key to .env. Then choose a name and optional spellings: 

ASSISTANT_NAME=Мира
ASSISTANT_ALIASES=Mira
Prepare models. Start talking.RUN

Install OpenClaw using its official guide. Setup creates a dedicated profile and downloads the speech models once. 

uv run clawsona setup
uv run clawsona openclaw-setup
uv run clawsona doctor
uv run clawsona

GOOD TO KNOW

A few honest answers.

Does everything run offline?

Whisper and Piper run locally after downloading the models. The default DeepSeek model, weather and search require internet. Direct Ollama mode can use a local model, without OpenClaw tools.

Can I interrupt it while it speaks?

Yes. Address the configured name during a reply and continue your question. Playback stops after recognition confirms the address. Headphones also support interruption by any phrase. Full acoustic echo cancellation is not implemented; loud speakers and overlapping voices can interfere with recognition.

Is it ready for every mini-PC?

CPU, microphone placement and noise matter. Whisper small with four CPU threads is the starting point. Test the real dialogue on your device and adjust the model, voice and pause length. No universal latency is promised.

What about music and other actions?

Weather and search are available through bounded tools. Yandex Music is experimental, disabled by default, and has not been validated end to end. The generated profile does not enable shell or arbitrary file access.

Is ClawSona free and open source?

The application is GPL-3.0-or-later: free to use, modify and redistribute under that license. Dependencies and voice models have their own terms. Provider API usage and subscriptions are separate.
