# Public voice samples

These samples were generated with ElevenLabs for the ClawSona project page.
They contain no microphone recordings or private conversations. Mira is an
example name, not a hardcoded application identity.

| File | Provider / voice | Exact text |
| --- | --- | --- |
| `hello-ru.mp3` | ElevenLabs / Roger | Привет! Я Мира. Давай поговорим. |
| `hello-en.mp3` | ElevenLabs / Roger | Hello! I'm Mira. What would you like to do today? |

Generated with Eleven v4 Turbo and encoded as MP3 by FFmpeg. They demonstrate
optional paid cloud speech, not the default local Piper voices, a live model
conversation, or recognition performance. Example dialogues are separate
illustrations; the audio player previews a voice, not every displayed message.
