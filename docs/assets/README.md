# Project artwork

Original, editable SVG artwork created for ClawSona:

- `mark.svg`: the shared project icon, 64 × 64.
- `cover.svg`: the GitHub README cover, 1440 × 600; `cover.png` is a raster export.
- `pipeline.svg`: the voice/agent/playback diagram, 1200 × 210.
- `social-card.svg` / `.png`: a 1200 × 630 social preview. Upload the PNG in the
  public repository's social preview settings when the repository exists.

The PNGs are deterministic SVG renders made with CairoSVG. No stock photography,
external fonts or third-party logos are embedded. Artwork is provided under the
project's GPL-3.0-or-later license; the OpenClaw name refers to the independent
upstream project, not an affiliation or endorsement.
